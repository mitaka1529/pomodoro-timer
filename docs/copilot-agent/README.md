## 変更履歴

### 2026/09/03 モードAを1事例1行に修正

モードAのExcel貼り付け用表が品番ごとに行を出力してしまう事象への対応。

- 指示文に「最優先ルール：モードAは1事例につき1行」を追加し、「事例」の定義と行を分けてよい条件を明記。
- 共通ルールの「品目で条件が異なる場合は行を分ける」を削除し、1事例1行と併記ルールに置換。
- 処理順序に「事例数の確定」と「行数と事例数の一致確認」を追加。
- 最終確認に行数チェックとセル内改行チェックを追加。
- ナレッジに「モードAの記録単位（1事例1行）」と「品番・品目ごとに条件が異なる場合の記載方法」を追加。
- ナレッジの各項目（要求値上げ率、妥結値上げ率、交渉結果、適用開始日、Excel行数ルール、共通出力ルール）から「行を分ける」記述を削除し、セル内併記に統一。
- 交渉結果が品番で混在する場合の代表結果の選び方を明記。
