# 海外調達検討 報告仕様

この文書は、「海外調達検討 報告作成」エージェントが使用する、計算定義、評価軸、判定基準、章立て、文言テンプレートおよび確認項目を定める。

エージェントの指示欄に記載された添付ファイル確認、シナリオ分離、推測禁止および処理順序を最優先とする。

# 1. 入力資料の読み方

## 1.1 見積比較Excelの典型構成

| 要素 | 内容 | 確認事項 |
|---|---|---|
| 対象品番 | 親品番（完成品）と構成部品（プレート等）の対応 | 親品番単価が構成部品の合計か、単体か |
| 現行単価 | 国内購入価格。複数工程（加工・ショット・鍍金等）の合計であることが多い | 工程ごとの単価と指示先（サプライヤー名） |
| 海外単価 | 外貨建て見積 × 為替レート。初回見積、再見積、当社希望値段など複数列がある | 各列の日付と前提条件 |
| 出荷実績 | 年度別の出荷数と売上 | 親品番ベースか、実績なし品番の扱い |
| 効果 | （海外単価 − 現行単価）× 出荷数。負がコスト削減 | 合計行の範囲、除外条件（SUMIF等） |
| 見積内訳 | 材料費、加工費、鍍金費、梱包費、輸出費用、管理費など | 含まれる費用と含まれない費用 |

## 1.2 シート名が異なるシートがある場合

同じレイアウトで数値が異なるシート（例：「効果」と「効果最大」）は、別シナリオである。どの見積列（初回／再見積）を参照しているかを海外単価の値から特定し、シナリオ名と前提条件を明記する。

## 1.3 既存の報告資料がある場合

既存資料の数値がどのシナリオの値かを特定する。条件付きシナリオの数値が基準値のように書かれている場合は、【既存資料との相違】で指摘する。

# 2. 計算定義

すべて資料に記載された為替レートと出荷数を用いる。独自の前提を置く場合は「案」または「感度」として明記する。

| 指標 | 定義 |
|---|---|
| 年度別効果 | Σ（現行単価 − 海外単価）× 当該年度出荷数。正が削減、負がコスト増 |
| 累計効果 | 対象年度の年度別効果の合計。原則3年 |
| 年平均効果 | 累計効果 ÷ 年度数 |
| 除外効果 | 特定顧客向け品番（型式サフィックス等で識別）を除いた効果 |
| 集中度 | 上位1品番（または上位3品番）の効果 ÷ 全体効果。年度別に示す |
| 海外が高い品番数 | 海外単価 ≧ 現行単価の品番数 ／ 単価比較可能な品番数 |
| 限定移管効果 | 上位品番のみを移管した場合の累計効果と年平均 |
| 為替感度 | レートを±10円、±20円動かした累計効果。海外単価は外貨 × レートで再計算 |
| 損益分岐レート | 累計効果がゼロになるレート ＝ 基準レート × Σ（現行単価 × 出荷数）÷ Σ（海外単価 × 出荷数）。全体、除外後、主力品番の3通り |
| 価格回答の到達度 | 先方の値下げ率 ÷ 当社の要求値下げ率。品番平均で示す |
| 原価構成比 | 見積内訳の各費目 ÷ 合計。サイズ・品番群ごとに平均 |
| 数量推移 | 主力品番の年度別出荷数と、全社売上に占める割合 |

丸めは万円単位の整数（3桁区切り）。率は整数%または小数1桁。レートは小数1桁。

# 3. 評価軸と判定基準

7つの評価軸で○△×を付け、総合判断を決める。

| 評価軸 | ○ | △ | × |
|---|---|---|---|
| 経済効果（基準シナリオ） | 年平均効果が明確にプラスで、除外後もプラス | 年平均効果はプラスだが除外後は小さい | 除外後がゼロ以下、または海外が高い品番が多数 |
| 経済効果（条件付きシナリオ） | 条件が既に満たされている | 効果はあるが条件（検査基準緩和等）が未合意 | 条件が実現不可能 |
| 効果の分散 | 上位1品番の集中度が50%未満 | 50〜65% | 65%以上 |
| 数量の安定性 | 主力品番の出荷が3年連続で安定または増加 | 年度間で2倍以上の変動 | 減少傾向または見通しなし |
| 為替耐性 | 損益分岐レートが基準レート＋20円以上 | ＋10〜20円 | ＋10円未満、または除外後が基準レート以下 |
| 品質リスク | 先方から具体的な懸念表明なし | 懸念はあるが対策提示あり | 先方が効果の大きい品番・工程で問題を自認 |
| 付随コスト | 金額化済みで正味効果がプラス | 未金額化 | 金額化済みで正味効果がマイナス |

総合判断の目安：

- ×が2つ以上 → 見送り（限定・条件付き再検討を付けてよい）
- ×が1つで△が3つ以上 → 条件付きで再検討
- ×がなく○が4つ以上 → 移管を推進

# 4. 結論の型

結論は次の3つから1つを選び、理由を3点以内で述べる。

1. 移管を推進する
2. 現時点では移管しない（国内調達継続）
3. 限定・条件付きで再検討する（対象品番と条件を明記）

限定・条件付きの場合は、再検討のゲートを3つ設ける。

| ゲート | 内容 | 担当 | 通過条件の書き方 |
|---|---|---|---|
| 数量 | 主力品番の翌年度以降の出荷見通し | 営業・購買 | 年◯個以上の見通し（案） |
| 品質 | 検査基準の緩和可否、サンプル評価、顧客合意 | 設計・品質保証 | 緩和範囲を顧客と合意し、サンプル合格 |
| コスト | 付随コストの金額化と正味効果、為替条件 | 購買 | 正味効果が年◯万円以上、かつ基準＋10円でも黒字（案） |

各ゲートに期限と、全ゲートの結果をもって判断する日と判断者を明記する。1つでも未達なら見送り確定とする旨を書く。

# 5. 章立て（スライド単位）

各スライドは「タイトル／サブタイトル（主張1文）／本文要素／図表」で構成する。

| No. | タイトル | 主な内容 | 図表 |
|---|---|---|---|
| 1 | 表紙 | 案件名、期間、結論の1文、主要数値3つ（基準効果、条件付き効果、集中度） | 数値カード |
| 2 | エグゼクティブサマリー | 判断、理由3点、次のステップ | 判断カード＋理由3枚 |
| 3 | 検討の前提と評価方法 | 対象、現行単価の構成、効果の定義、含まない費用、シナリオ定義表、読み方の注意 | シナリオ表 |
| 4 | シナリオ別の効果 | 年度別効果、累計、除外効果、海外が高い品番数、示唆 | 年度別棒グラフ、集計表 |
| 5 | 効果の集中 | 上位品番の集中度、上位品番表、示唆 | 集中度棒グラフ、上位表 |
| 6 | 数量と為替への感度 | 主力品番の数量推移、売上構成比、為替感度表、損益分岐、示唆 | 数量棒グラフ、感度表 |
| 7 | サプライヤー回答と品質リスク | 回答原文、原価構成比、効果とリスクの一致、判断主体 | 原文カード、構成比グラフ、論点3枚 |
| 8 | 金額化していないコスト・リスク | 項目、内容、性質、効果への影響、評価の目安 | 一覧表 |
| 9 | 総合評価と結論 | 評価軸7つの○△×、結論、先方への回答方針、代替策 | 評価表、結論カード |
| 10 | 次のアクション | 3ゲート、担当、期限、通過条件案、最終判断日 | ゲートカード3枚 |
| 11 | 付録 | 品番別効果一覧（上位）、データ注記、既存資料との相違 | 一覧表 |

# 6. 文言テンプレート

## 6.1 サブタイトル（主張）

- 「現行基準で有効な◯◯見積では3年間◯万円。◯◯を除くと効果は消える」
- 「◯◯が効果の◯〜◯%。この1品番の前提が崩れると案件全体が成り立たない」
- 「効果は主力品番の数量と為替に比例する。◯◯見積は◯円/USDで効果がゼロになる」
- 「効果の大きい◯◯は、先方が『◯◯』に最も困っている工程・サイズと一致する」

## 6.2 結論カード

「全品番の海外移管は見送る／国内調達を継続する／先方には『◯◯』と回答する／◯◯のみ、3ゲートを満たした場合に限定移管を再検討する／並行して国内サプライヤーへ◯◯の価格交渉を打診する」

## 6.3 読み方の注意（既存資料との相違がある場合）

「元資料の『◯万円』は条件付きシナリオの数値。現行基準で有効なのは基準シナリオの◯万円」

# 7. 未金額化コストの標準項目

| 項目 | 内容 | 性質 |
|---|---|---|
| 立上げ費用 | 初回サンプル・承認、図面/仕様の擦り合わせ、監査・出張 | 一時費用 |
| 受入検査 | 外観・寸法・表面処理の検査工数増。基準変更時は判定基準の再整備 | 継続費用 |
| 輸送・関税・通関 | 見積に含まれる費用（梱包・輸出費用）と含まれない費用（海上運賃・関税・国内輸送・通関）を区別 | 継続費用 |
| 在庫・リードタイム | 安全在庫の積み増し、発注ロットによる余剰在庫 | 運転資金 |
| 為替 | 外貨建ての場合の変動リスク。円建て化・ヘッジ条件の有無 | 変動リスク |
| 品質不良 | 廃棄・再加工・納期遅延・顧客影響 | 損失リスク |
| 既存サプライヤー | 稼働減、戻す際の再立上げ、関係・BCP | 関係・BCP |

# 8. 出力前の確認項目

- 基準シナリオと条件付きシナリオの効果額を分けて示したか
- 除外効果、集中度、海外が高い品番数を示したか
- 為替感度と損益分岐レートを3通り（全体、除外後、主力品番）示したか
- サプライヤーの発言を原文で引用し、効果の大きい品番・工程と結び付けたか
- 未金額化コストを一覧化し、正味効果が未確定であることを明記したか
- 評価表の○△×と結論、サマリー、ゲートが一致しているか
- 主要数値の出典（ファイル名・シート名・セル範囲または計算式）を【数値根拠】に記載したか
- 提案した閾値に「案」と付けたか
- 資料にない内容を創作していないか

# 9. スライドデザイン仕様

報告資料をPowerPointに落とす際の共通規則。エージェントはスライド単位の出力にこの規則を前提とした「図表の指示」と「配置の指示」を含める。

## 9.1 基本設定

| 項目 | 規則 |
|---|---|
| スライドサイズ | 16:9（10インチ × 5.625インチ） |
| フォント | 本文・見出しとも Meiryo。社内標準フォントがある場合はそれに置き換える |
| 余白 | 上下左右 0.5インチ以上。要素間は 0.15〜0.3インチで統一 |
| 1枚の情報量 | 主張1文＋図表1〜2点＋補足カード1点まで。本文の箇条書きは3〜4項目、各1〜2行 |
| 出典 | スライド上には書かず、ノート欄に記載する。付録に「データ注記」を置く |
| フッター | 左に「案件名｜部署｜日付」、右にページ番号。9pt、灰色 |

## 9.2 配色

用途を固定した5色を使う。色は意味を持たせ、装飾には使わない。

| 用途 | 色 | 使用箇所 |
|---|---|---|
| 基調（濃紺） | #1B2A41（補助 #24364F） | 表紙の結論カード、判断・結論カードの背景、表の見出し行、番号丸 |
| 削減・肯定（青緑） | #0E7C7B（淡色 #D7EEEC） | 基準シナリオの系列、効果額、ゲート番号 |
| 注意・条件付き（琥珀） | #B7791F（淡色 #F6E9D2） | 条件付きシナリオの系列、「読み方の注意」「通過条件」カード、△判定 |
| コスト増・否定（赤） | #B23A48（淡色 #F4DDE0） | コスト増の数値、×判定、「合理性が弱い」等の警告カード |
| 参考（灰） | #B9C2CE | 参考シナリオの系列 |
| 本文 | #1F2937、補足 #6B7280、罫線 #E3E8EF、カード地 #F5F7FA | 文字・表・カード |

- 背景は全スライド白。濃紺は表紙の結論カード、判断・結論カード、最終判断の帯など「結論を示す要素」だけに使う。表紙の主要数値は用途色（青緑・琥珀・赤）で色分けする。
- 削減はプラス表記、コスト増は「▲」で示し、赤で表示する。

|---|---|

| サブタイトル（主張1文） | 12.5pt 灰色 |
| 表紙タイトル | 32pt 太字 濃紺 |
| 表紙の主要数値 | 26pt 太字 用途色 |
| カード見出し | 11〜13pt 太字 |

| 表 | 見出し 9〜10pt 白太字（濃紺地）、本文 8.5〜10pt |
| 図表の値ラベル | 9〜10pt |
| 注記・フッター | 8.5〜9pt 灰色 |

## 9.4 レイアウトの型

スライドごとに型を変え、同じ型を連続させない。

| 型 | 構成 | 使用スライド |
|---|---|---|
| 表紙 | 白背景。タイトル、副題、濃紺の結論カード（横長）、灰色地の主要数値カード3枚 | 1 |
| 判断＋理由 | 左に濃紺の判断カード（3列幅）、右に番号付き理由カード3枚（縦積み） | 2 |
| 前提＋表 | 左に項目カード4枚、右にシナリオ表と注意カード | 3 |
| グラフ＋表＋示唆 | 左にグラフ（5.4インチ幅）、右に集計表と「ここから言えること」カード | 4、5、6 |
| 原文＋グラフ＋論点 | 上段に原文引用カードと構成比グラフ、下段に番号付き論点カード3枚 | 7 |
| 一覧表 | 全幅の表、下に「評価の目安」の帯 | 8 |

| 付録 | 左に品番別一覧表、右にデータ注記カード | 11 |

## 9.5 図表の規則

- グラフは画像ではなくPowerPointのネイティブグラフで作る。
- 棒グラフは縦棒、値ラベルを棒の上に表示、縦軸の最小値は0、目盛線は薄い灰色、横軸の目盛線はなし。
- 系列色は用途色に従う（基準＝青緑、条件付き＝琥珀、参考＝灰、数量＝濃紺）。単一系列のときは凡例を消す。
- グラフタイトルは「何の・何を・単位」を1行で書く。例：「年度別 削減効果（万円）」。
- 表は見出し行を濃紺地・白文字、罫線は薄い灰色、数値は右揃え、品番は左揃え、判定は中央揃え。
- 表のセル内で改行させない。列幅が足りない場合は単位を見出しやキャプションに逃がす。
- 為替感度表の損益分岐行は琥珀の淡色で塗る。

## 9.6 カードと装飾

- 角丸の矩形カード（角半径0.08インチ）を統一モチーフとする。影は付けない。
- 番号は塗りつぶしの丸（直径0.34インチ）に白数字で入れる。
- タイトル下の飾り線、スライド端の帯、カード端の縦線は使わない。
- アイコンや画像は使わない。視覚要素はグラフ、表、数値カード、カードで構成する。

## 9.7 文言の規則

- サブタイトルは「主張」を1文で書き、事実の羅列にしない。
- 数値は万円単位（3桁区切り）、率は%、為替は円/USD、日付はyyyy/mm/dd。
- 各スライドの示唆は「ここから言えること」の見出しで3項目以内。
- 提案値には「（案）」を付ける。

## 9.8 出力時の確認

- 文字がカードや表からはみ出していないか。
- 表とカードが重なっていないか。要素間に0.15インチ以上の間隔があるか。
- 同じレイアウトが連続していないか。
- 用途色の意味が全スライドで一致しているか（青緑＝基準・削減、琥珀＝条件付き・注意、赤＝コスト増・否定）。
